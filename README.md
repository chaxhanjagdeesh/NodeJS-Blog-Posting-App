# Node.js Blog Posting App

A simple blog posting application built using Node.js, Express.js, and EJS.  
Users can create, view, and manage blog posts through a clean and responsive interface.

---

## Features

- Create new blog posts
- View all blog posts
- Dynamic routing with Express.js
- Server-side rendering using EJS
- Responsive UI
- REST-style routing structure

---

## Tech Stack

- Node.js
- Express.js
- EJS
- HTML5
- CSS3
- JavaScript
